# NotePro

A personal handwriting notebook app for the Galaxy Tab S10 Ultra and S Pen, built natively on Android's Ink library.

**Install:** open the [latest release](https://github.com/jonatankettner-bot/notepro/releases/latest) on the tablet and download `NotePro.apk`.
After that the app updates itself: when a new version is out it shows "עדכון זמין".
